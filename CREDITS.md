# Asset credits

## Weapon display geometry

Sourced from the Kimi design asset library:

- **M4-style rifle display** — asset ID `02-G1-0011`.
- **Sniper Rifle — olive display asset** — asset ID `02-G1-0012`.

The supplied evaluated geometry and named transforms were adapted into single-mesh, vertex-colored GLB game assets, then welded and simplified for real-time delivery. Material base colors and embedded color-map averages were baked into vertex colors; the original high-material-count runtime modules and texture maps are not shipped. Weapon placement preserves the source hierarchy's evaluated transforms during processing and uses an outer placement group in the game.

The source packages did not declare a separate CC license for the display geometry. Their included `THREE-LICENSE.txt` covers the Three.js runtime code, not a claim about the geometry's license.
