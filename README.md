# SANDLINE — بروتوكول خط الرمل

لعبة تصويب تكتيكية فردية ثلاثية الأبعاد داخل المتصفح، مبنية بـ Three.js. هي نموذج أصلي مصغّر مستوحى من أسلوب ألعاب الجولات التكتيكية، وليست نسخة من Counter-Strike ولا تستخدم خرائطها أو شعاراتها.

## الهدف

اكسب أغلبية 3 جولات. في كل جولة، صفِّ جميع الخصوم قبل انتهاء الوقت وحافظ على صحتك. القتل يمنح رصيدًا، وبين الجولات يمكن شراء قناصة أو درع.

## التحكم

- **W / A / S / D أو الأسهم:** الحركة.
- **الماوس:** النظر والتصويب.
- **زر الفأرة الأيسر:** إطلاق النار.
- **زر الفأرة الأيمن:** التصويب بالمنظار.
- **R:** إعادة التلقيم.
- **1 / 2:** تبديل السلاح.
- **Shift:** الركض للأمام.
- **Esc أو P:** إيقاف ومتابعة.
- **Space:** بدء المهمة أو الجولة من الشاشات المناسبة.

## التشغيل

```bash
npm install
npm run dev
```

للإنتاج:

```bash
npm run build
npm run preview
```

## الأنظمة الرئيسية

- ثلاث جولات بصعوبة وعدد خصوم متزايدين.
- مقاتل، مهاجم سريع، وخصم ثقيل بسلوك ومدى مختلفين.
- بندقية آلية وقناصة، مع ارتداد وانتشار وذخيرة وتلقيم ومنظار.
- اقتصاد جولات ومكافآت قتل وشراء درع يمتص جزءًا من الضرر.
- اصطدام بالجدران والغطاء، خط رؤية للخصوم، وإصابات Raycaster مع ضرر مختلف للرأس.
- مؤثرات إطلاق وإصابة وآثار رصاص وصوت مُولّد عبر Web Audio.
- إيقاف، فوز، خسارة، وإعادة تشغيل كاملة.

## تقنيات

- حلقة منطق ثابتة عند 60Hz مع عرض منفصل.
- هندسة إجرائية للخريطة، وتصادم دائرة مع صناديق محورية.
- نماذج سلاح GLB محسّنة إلى شبكة واحدة بألوان خامات مخبوزة.
- تجميع آثار الرصاص والجسيمات في موارد محدودة السعة.
- خفض دقة العرض تلقائيًا عند انخفاض الأداء.
- أفضل عدد قتلى يُحفظ محليًا في المتصفح فقط؛ لا توجد مزامنة أو لوحة صدارة عبر الأجهزة.

## التحقق

تم اختبار البناء والتشغيل في Chromium، بما يشمل الحركة، إطلاق النار الفعلي والإصابة، التلقيم، المنظار، الشراء، الإيقاف والمتابعة، كتم الصوت، الانتقال بين الجولات، الفوز والخسارة وإعادة التشغيل وتغيير حجم النافذة. سجّل أزحم مشهد مختبر 89 استدعاء رسم ونحو 41 ألف مثلث بعد تحسين النماذج. بيئة الاختبار المتاحة تستخدم SwiftShader، لذلك لا تُعد قراءاتها قياسًا لأداء بطاقة رسومية حقيقية.
